# Crew

The Section 9 roster page: who's on the team, what each agent does, budgets and
standing orders. Published at `/crew/` by the Pages workflow. Avatars are
original drawings (sources in `petterfranzen/agent-manager`, `agents/avatars/`).

The roster's source of truth is `agents/roster.toml` in agent-manager; this page
is the human-friendly view. Agents may change this folder on `task/*` branches.
